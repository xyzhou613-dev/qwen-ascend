## 实现与数值边界

* 归一化保留原 `(x*x).sum(-1,keepdim=True)`，两步均保留 BF16 中间舍入。用原 CANN 表达式生成 65536 项 BF16 查表，融合 epsilon/Rsqrt 的查表与末尾 BF16 乘法；每进程约 128 KiB。只在单 token、16×128、匹配 stride 的路径启用，其他形状回原路径。不是用自写近似 Rsqrt 替换 CANN。
* DeltaNet 缓存按设备区分的三角 mask、对角索引、8×8 单位矩阵和 block mask，复用完整 `cumul.exp()`；BMM、逆系统求解、状态递推与结合顺序保留，原 2048 窗口不变。
* 源码默认关闭；正式 p275.sh 仅新增上述两项默认值与透传。r142 首块、r143 索引后处理、权重/量化、FP32 递推精度和现有 27B 配置保留。

组件图内重复以摊薄图启动开销，显式 replay 后对拍；设备微测不等同于 HTTP。decode 归一化约 12→9 µs；2048-token DeltaNet 约 7.95→7.87 ms，另有集成分支复测。不能把两卡设备时间相加后直接乘块数预测 TTFT。未新采完整模型 profiler 轨迹。

## Raw 候选否决

| 候选 | 6k NLL / top1 | 24k NLL / top1 | 结论 |
|---|---:|---:|---|
| r143 | 1.722880 / .6131 | 1.127045 / .7387 | 参考 |
| 全量 Raw qkv+z、b+a、全注意力 q/k/v | 1.721153 / .6080 | 1.142162 / .7337 | 长文质量回退，否决 |
| 仅 decode Raw b+a；prefill 用原形状共享存储视图 | 1.743139 / .5930 | 1.124558 / .7286 | 自然文档质量回退，否决 |

全量合并在 decode 微测及 L00 层计时中有收益，但改变 CANN tiling，不能以调用减少替代整模型验收。b+a 扩展测试覆盖 36 层×128 单 token 输入、5 档幅度，共 442368 输出，有 89 个不同值；这些微小变化仍可在完整模型放大。未将任何 Raw 候选装入正式部署。失败源码、层级数据和质量结果分别保留，不能挑选 NLL 改善的文本来宣称通过。

自写 AscendC Rsqrt 后处理同样被否决：真实 BF16 conv/SiLU 输入存在大量差异；最终只保留 CANN 生成查表的精确版本。初版微测未显式重放图、图太小受启动开销支配的数据已弃用。

## 部署、恢复与复现

正式入口 `/root/ascend-dev/p275.sh`。本次启动到 HTTP ready 为 251 s，单独记录，不把权重装配完成当作服务就绪。测试在服务器独立 systemd 控制器中执行，停服前保存配置与文件备份，独立到期恢复覆盖断链；候选成功后用新的部署恢复定时器接管，停止候选后再安装新共享库。没有在正式模型占卡时另起完整 Engine。

诊断 quality 路由只在隔离副本，未安装到正式 server.py。正式入口重新 HTTP ready 后完成 8k、256k 与缓存验收，并核对源码、ELF、启动配置与 health。管理器、watchdog 恢复，移除临时 drop-in、租约、恢复 timer 和本轮私有环境文件。

曾出现诊断路由放在启动语句之后导致 404，已修复并实际回退；另一次恢复脚本修改时发生读取位置异常，正式服务已恢复但管理器收尾需补正，已完成。后续文件以校验后的原子替换安装；watchdog 使用独立生命周期，避免随实验控制器 cgroup 退出。相关失败不会记作算法性能结果。

功能回退：暂停同机模型切换后，以 `FNX_NORM_POST=0 FNX_DELTA_REUSE=0` 通过原入口重启。完整文件回退：停服务，运行证据目录 `deployment_files.py rollback`，再用原 p275.sh 启动；备份在 deployment-backup/。27B 来回切换本轮未重跑。

编译：`bash kernels/l2norm_post/build.sh /明确路径/libfnx_norm_post.so`，在使用进程停止后安装。启用脚本 `scripts/r144-enable.py` 可先加 `--check`；只识别已验证的 p275 锚点，漂移则拒绝写入。

仓库 `benchmarks/r144-exact-norm/` 保存白名单证据与探针；原始目录 `/models/fnx-diagnostics/r144-raw-norm-20261112`。未交付完整进程环境、凭据、权重或图缓存。
