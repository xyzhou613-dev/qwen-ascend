## 实现

| 原路径 | r143 |
|---|---|
| 原生四头打分→缩放→构造因果比较→MaskedFill→TopK | 在原生四头求和内完成FP32除法和因果掩码，再走原TopK |
| decode/较小形状：torch原有ReLU/四头归约→缩放→比较→MaskedFill | 保留原torch归约，仅将缩放和掩码融合；不支持形状使用旧路径 |

新增kernels/index_post和fnx/index_post.py，通过FNX_INDEX_POST=1启用，默认关闭。分数头维度128、四token池化、组数按2048对齐；不能直接套用到不同定标或池化语义的模型。权重、量化、MatMul、TopK、KV/FP32递推状态和r142分块策略均保留。移除不再需要的因果范围临时张量与重复写回。

生产固定mode1 Div。把除法改写为乘FP32倒数的mode0在本轮范围测试中累计出现6667213个不同FP32输出，未采用。测试包含36组shape/位置，以及2097152个宽指数/尾数的随机非负有限FP32位型；这不是穷举全部FP32值。mode1输出位型和TopK一致。
