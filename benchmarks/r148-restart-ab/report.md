# r148 重启A/B：归一化融合更快，但未通过精确性验收

2026-11-12，192.168.18.206，2×Ascend 910B4-1（物理3/5、两进程24+24），CANN9.1.0、驱动26.1.1、torch2.10.0+cpu、torch_npu2.10.0.post4。正式源码起点794a22e / r144，测试前仓库HEAD f53ec03且干净。

结论：候选fresh 8k / 256k输出速度实测提高约**2.42% / 2.55%**，但12k质量样本及一份8k回答出现差异，不符合精确融合门禁，**没有部署候选，正式服务已恢复r144**。不能把此候选记录成已交付提速。

## 整模型HTTP结果

| 场景 | r144 TPOT, ms | 融合候选 TPOT, ms | 输出速度变化 |
|---|---:|---:|---:|
| fresh 8k（三次中位） | 33.89 | 33.09 | +2.42% |
| fresh 256k（各一次） | 34.59 | 33.73 | +2.55% |
| 256k缓存重复（各一次，非流式） | 34.21 | 33.35 | +2.58% |


输出速度变化按`TPOT基线/TPOT候选-1`计算；不是TPOT降低百分比。fresh 8k TPOT降低约2.36%，每token省0.80ms；fresh 256k省0.86ms。8k为8064输入+128输出，每版本三份固定输入；256k为262016输入+128输出、每版本一次，不外推256k输入后追加8k输出。缓存重复明确单列，新增prefill=0；不充当fresh prefill收益。

8k HTTP TTFT中位：3.858→3.847s。256k HTTP TTFT：69.938→69.914s，约69.9s，没有可确认的长文TTFT改善。该改动针对decode归一化，不能据微小TTFT波动宣称prefill提速。

测试暂停已识别的FNX watchdog和model-switch管理器，停止原服务后，每次只启动一份完整Engine。r144基线和候选各重新加载，在仅本机的127.0.0.1:19002测量，避开外部业务排队。配置、权重、冻结HTTP输入一致，候选仅启用FNX_NORM_FUSED。两次成功启动到HTTP ready分别244.8 / 242.1s，单列启动时间，不算TTFT。第一轮基线导入acl失败已修复，未计入这些时间或性能数据。

6k和24k样本逐目标NLL/argmax全部相同；12k有68/199个目标NLL不同，首次可观察差异为尾部索引130（0起算），最大单目标差约0.000782195。三份共597个目标的argmax均相同。12k均值稍降不构成通用质量更好的证据，尤其它是重复服务文本；本轮不能宣称保持精确数值路径。

三份fresh 8k完整回答一致性为[False, True, True]，第一份在第60个字符起有措辞变化，长度266→269；256k fresh回答相同，三事实均3/3，缓存回答一致性为True。没有把措辞变化直接称为事实质量下降，但它进一步证明新路径不再逐位等价。历史100题未重跑，未额外重跑旧200-token loss；质量门禁采用真实plan_prefill/prefill_chunk/finish_prefill与597个尾部decode目标。

本轮完整L00/L12/L24/L44输出、BF16历史及FP32状态对拍曾通过，覆盖decode及128/512/2048行prefill；此前全部36层DeltaNet子路径样本也通过。这些样本仍未覆盖这次全模型分歧，说明局部一致不能替代整模型门禁。

## 已保存的归一化反例

额外算子探针不启动Engine。常规随机/SiLU分布扫描2,097,152行未找到差异；改为稀疏舍入边界输入后，18,432行内找到反例，并回到原单token形状`[1,16,128]`复验。

每行只有四个非零值：索引60/99为2^-12，61为1/16，80为1。关闭query缩放，原CANN平方/ReduceSum/查表路径在索引80输出**0.99609375**，新融合路径输出**1.0**；16行共64个非零输出不同。输入的平方均可精确表示，这证明新的归约融合未保持原数值路径，不能归咎于query缩放。已保存四个小型合成张量及可复现脚本，不含用户会话激活。

这不是从12k失败请求中抓取的真实中间张量，因此尚未逐算子证明它与那次全模型分歧是同一个首次触发点。下一版需保留原CANN归约或复刻其累加/舍入行为，再重走整模型验收，不能因此次性能更快而跳过。

原稀疏搜索记录沿用了旧脚本的`silu`元数据字段，该字段在此不适用；生成器实际为上述稀疏BF16常量。rounding-reproducer-summary.json明确标注，原输入与对拍结果未改。
