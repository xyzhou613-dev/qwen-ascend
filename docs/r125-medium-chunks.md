# r125：中等预填分块

2026-11-10，同机独占 2×910B4，48 层 24+24，262144 窗口。基于 71daa94；未改变权重、路由、量化、KV 或 FP32 递推算法。

主块仍为 8192。分块图由 `8192,4096,512,128` 扩展为 `8192,4096,2048,1024,512,256,128,124`，避免不足 4096 行的尾部反复执行多个 512/128 行块。两级流水及各 index cap 捕获相同形状，保留动态专家路由。

| 同机 HTTP 测例 | 原配置 | 中等分块 | 变化 |
|---|---:|---:|---:|
| 8k TTFT，3 次中位数 | 5.298 s | 4.949 s | -6.6% |
| 8k TPOT，中位数 | 45.42 ms | 45.53 ms | 基本不变 |
| 256k TTFT，单次 | 86.384 s | 84.454 s | -2.2%，需留意单次波动 |
| 256k TPOT | 46.81 ms | 46.97 ms | 基本不变 |

8k 输入 8064、256k 输入 262016，输出均 128 token；独立文档编号防止缓存命中；TTFT 为服务本机客户端首个文本增量，输出速度为 1000/TPOT。不能把新增形状的局部收益解释为算力达到硬件上限。

精度与功能：200-token NLL 2.165267（冻结参考 2.164792±0.01）；15 个不对齐尾块全部通过；256k 三事实 3/3，重复请求新增 prefill=0；追问仅新增 29 token 并回答 7319。历史 100 题本轮未重跑。原始记录保存在 benchmarks/r125。

代价：捕获的图更多，本次候选从进程启动到健康通过约 261 秒。该配置通过隔离候选验收，脚本已记录；实际生产发布待本轮其余候选收敛后统一回归。回退为旧的四种分块并重启。

r123 曾被并发启动的 27B 抢占设备并替换 8000 端口，该轮无效，不计入本表。后续客户端在每次请求前校验 Flash Next 模型 ID、候选 PID 与运行目录；身份不符立即中止。
